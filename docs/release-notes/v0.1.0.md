First release.

- Open a SQLite database and browse its tables, views, indexes, and triggers.
- Page, sort, and filter table rows, and edit rows in base tables.
- Run read-only SQL with a 30-second timeout, a 1000-row result limit, and cancellation.
- View per-table statistics: row and column counts, indexes, foreign keys, triggers, and storage use.
- Export a table page or a query result to CSV.
- Packages: Debian `.deb`, portable Linux `.tar.gz`, and a universal macOS `.dmg` (ad-hoc signed, not notarized).
